# Idea del proyecto: TaskFlow

## Descripción
TaskFlow es una aplicación web de gestión interna para un restaurante. Permite al manager organizar empleados, turnos, tareas, vacaciones y formación desde una única plataforma.

---

## Problema que resuelve
Actualmente la gestión del personal en restaurantes suele hacerse con herramientas separadas o manualmente. TaskFlow centraliza toda la información en un único sistema.

---

Encargados de equipo
Supervisores de turno

## Persistencia de datos

La aplicación utilizará principalmente LocalStorage para guardar información en el navegador del usuario.

En caso de necesitar datos iniciales o simulados, se podrá utilizar una API o datos mock para cargar información de ejemplo.

No se requiere una base de datos en esta fase del proyecto.

## Problema que resuelve

La gestión del personal en restaurantes suele hacerse con herramientas dispersas o de forma manual, muchas veces incluso en papel. Esto genera desorganización, pérdida de información y falta de control centralizado.

El uso de papel implica además problemas de almacenamiento, organización física de documentos y un impacto negativo en el medio ambiente debido al consumo innecesario de recursos.

TaskFlow soluciona este problema centralizando la gestión de empleados, turnos y tareas en una única aplicación digital, más eficiente, moderna y sostenible.

## Usuario objetivo

El usuario objetivo de TaskFlow son personas que gestionan equipos en restaurantes, como:

Managers de restaurante
Encargados de sala o cocina
Supervisores de turno
Empleados del restaurante (camareros, cocina, etc.)

Los empleados también tendrán acceso a la aplicación para consultar su información personal, como turnos asignados, días de vacaciones, documentación disponible, solicitar días libres o subir documentación requerida.

Estas personas necesitan una herramienta para organizar el personal, asignar tareas y controlar la operativa diaria de forma sencilla y centralizada.

## Funcionalidades principales

Gestión de empleados
Asignación de tareas por turno
Visualización de turnos diarios
Control de vacaciones y días libres
Consulta de tareas pendientes y completadas
Acceso de empleados a su información personal
Subida y consulta de documentación

## Funcionalidades opcionales

Estadísticas de asistencia del personal (porcentaje de días trabajados vs. ausencias)
Control de absentismo
Integración o consulta de datos de entrada y salida del sistema de fichaje existente (para detectar retrasos o faltas recurrentes)
Sistema de notificaciones internas personalizadas para empleados (avisos de turnos, incidencias, recordatorios)
Notificaciones generales para toda la plantilla (comunicados de empresa)
Avisos relacionados con formación obligatoria o eventos internos
Filtros avanzados de tareas
Búsqueda de empleados
Exportación de datos (PDF o Excel)

## Mejoras futuras

Sistema de autenticación de usuarios (login con roles)
Roles y permisos avanzados (admin, manager, empleado)
Base de datos real para persistencia de datos
Aplicación móvil para empleados
Integración completa con sistemas de fichaje externos
Panel avanzado de analítica de asistencia y turnos
Automatización de avisos y alertas inteligentes
