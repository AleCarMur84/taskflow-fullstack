# Metodologías de desarrollo

## Agile
Agile es una metodología de desarrollo de software basada en la flexibilidad, la entrega incremental y la mejora continua. Su objetivo es adaptarse a cambios durante el desarrollo y entregar valor de forma rápida y constante.

---

## Scrum
Scrum es un framework dentro de Agile que organiza el trabajo en ciclos llamados sprints.

Elementos principales:
Product Owner: define prioridades
Scrum Master: facilita el proceso
Equipo de desarrollo: construye el producto
Sprint: periodo corto de trabajo
Backlog: lista de tareas

---

## Kanban
Kanban es un sistema visual de gestión de tareas basado en un tablero con columnas como:
Backlog
To Do
In Progress
Review
Done

Las tareas se mueven de forma continua.

---

## Diferencias
Scrum trabaja por sprints, Kanban es continuo
Scrum tiene roles definidos, Kanban no necesariamente
Kanban es más flexible

---

## Uso en este proyecto
En este proyecto se utilizará Kanban para organizar tareas de desarrollo debido a su flexibilidad.
