# Retrospective - TaskFlow FullStack

## Qué he aprendido

Durante este proyecto he aprendido a desarrollar una aplicación fullstack utilizando React con TypeScript en el frontend y Node.js con Express en el backend. He entendido cómo se comunican ambas partes a través de una API REST.

También he aprendido a estructurar un proyecto en capas (frontend, backend y servicios), y cómo separar responsabilidades entre cliente y servidor.

---

## Conexión frontend - backend - API

El frontend desarrollado en React consume una API REST creada con Express en el backend. La comunicación se realiza mediante fetch, utilizando endpoints para crear y obtener empleados.

El backend gestiona los datos y expone rutas como GET y POST, mientras que el frontend se encarga de mostrar la información y permitir la interacción del usuario.

---

## Problemas encontrados

Uno de los principales problemas fue la integración entre frontend y backend, especialmente al desplegar en producción.

También surgieron errores relacionados con la actualización del estado en React y la sincronización de datos entre la API y la interfaz.

Otro problema fue la configuración del despliegue en Render y Vercel, así como la correcta configuración de las rutas de la API.

## Reflexión final

Este proyecto me ha permitido comprender mejor el desarrollo fullstack y cómo todas las piezas de una aplicación web trabajan juntas.

Ha sido un proceso con dificultades, especialmente en la integración y despliegue, pero me ha ayudado a consolidar conocimientos importantes para el desarrollo web moderno.
