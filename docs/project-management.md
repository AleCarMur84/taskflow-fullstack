# Project Management - TaskFlow

Este proyecto se está organizando siguiendo una metodología tipo Agile.

## Herramienta de organización
Se ha utilizado Trello para gestionar el flujo de trabajo del proyecto.

## Estructura del tablero
Backlog
Todo
In Progress
Review
Done

## Forma de trabajo
Cada funcionalidad se divide en tareas técnicas
Las tareas se mueven entre columnas según su estado
Se revisa el progreso de forma iterativa

## Objetivo
Mantener una organización clara del desarrollo y simular un flujo de trabajo profesional en equipo.
