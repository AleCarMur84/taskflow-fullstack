# Componentes - TaskFlow

## Navbar
- Componente de navegación principal
- Usa React Router para enlaces
- Aplica Tailwind para layout

## Card
- Contenedor reutilizable
- Usa `children`
- Opcionalmente muestra título

## Input
- Input controlado
- Tipado con TypeScript
- Usado en formularios

## Modal
- Ventana emergente reutilizable
- Controlado por estado (isOpen)
- Cierra con overlay o botón

## EmployeeList
- Lista de empleados
- Consume datos tipados desde Context API
- Render dinámico con map

## EmployeeForm
- Formulario controlado
- Añade empleados al estado global
- Usa useState para inputs
